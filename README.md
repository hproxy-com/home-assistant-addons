# HProxy add-ons for Home Assistant have moved

The add-on lives in **[proxy-all-in-one-tool](https://github.com/hproxy-com/proxy-all-in-one-tool/tree/main/home-assistant)**
now, with its whole history, and that repository is the one to add to Home Assistant:

[![Add this repository to your Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fhproxy-com%2Fproxy-all-in-one-tool)

Added this address before? In Home Assistant, **Settings → Add-ons → Add-on store → ⋮ → Repositories**:
remove `https://github.com/hproxy-com/home-assistant-addons` and add
`https://github.com/hproxy-com/proxy-all-in-one-tool`. Your settings stay, and the add-on keeps
getting updates from there.

This repository is read-only.
